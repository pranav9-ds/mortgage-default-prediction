# Data

The dataset is not included in this repo due to Freddie Mac's licensing terms.

## How to download

1. Go to [Freddie Mac's Clarity Data Intelligence portal](https://claritydownload.fmapps.freddiemac.com/CRT/#/sflld)
2. Register for a free account
3. Download the **2015 Sample Dataset** (`sample_2015.zip`)
4. Extract and place these two files in this folder:
   - `sample_orig_2015.txt` (origination data)
   - `sample_svcg_2015.txt` (monthly performance data)

The notebook expects these filenames in the `data/` directory.
